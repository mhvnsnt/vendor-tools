# vendor-tools

Re-downloadable vendor software used in the Western Heart pipeline.
Binaries live as release assets (see Releases). Each tool has its own folder
with version, source URL, and retrieval date.

Tools:
- tahoma2d/ — Tahoma2D (2D animation)
- cascadeur/ — Cascadeur (AI-assisted keyframe animation)
- krita/ — Krita (digital painting)
- natron/ — Natron (compositing)
- ppsspp/ — PPSSPP (PSP emulator, for Tekken 6 PSP teardown verification)
- storyboarder/ — Storyboarder (storyboarding)
- inkscape/ — Inkscape (vector graphics)

Per TOOLS-TO-STORE LAW: everything pulled in gets stored here before leaving disk.
